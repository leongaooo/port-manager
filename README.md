# 端口管家

一个面向 Windows 开发环境的本机进程与监听端口管理工具。

这是一个仅运行在本机的 Windows 进程与监听端口管理页。它不需要安装 npm 依赖，Node.js 18 或更高版本即可运行。

## 启动

双击 `start.bat`。服务启动后会自动打开：

```text
http://127.0.0.1:43127
```

重复双击时，如果端口管家已经运行，会直接打开现有页面，不会重复启动服务。

## 页面能力

- 查看 TCP/UDP 监听地址、端口、PID、程序路径和完整命令行。
- “监听进程”聚焦正在占用端口的程序。
- “全部 Node”包含未监听端口的 npm、Vite、MCP 等 Node 子进程。
- 按端口、PID、进程名称、项目路径或命令行搜索。
- 手动刷新，或设置 3、5、10、30 秒自动刷新。
- 使用左侧复选框选择多个进程，表头复选框可选择当前筛选结果，顶部“全部结束”执行批量操作。
- 结束单个进程，或结束整个进程树。
- 从网页右上角关闭端口管家服务。

## 权限与安全

默认以普通用户权限运行，可以结束当前用户启动的大部分开发服务。遇到“拒绝访问”时，先在网页关闭服务，然后右键 `start.bat`，选择“以管理员身份运行”。不建议长期以管理员权限运行。

服务只监听 `127.0.0.1`，不会暴露到局域网。每次启动都会生成随机操作令牌；结束进程前还会再次校验 PID 与启动时间，降低 PID 重用导致误操作的风险。Windows 关键进程与端口管家自身不能通过普通结束按钮关闭。

批量结束最多选择 50 个进程。服务会先校验全部目标，任何目标失效或受保护时整批拒绝；执行阶段若个别进程因权限不足失败，页面会保留失败项并显示结果。

## 修改端口

默认端口被其他程序占用时，可在命令提示符中运行：

```bat
set PORT=43128
start.bat
```

## 开发验证

```powershell
npm run check

```

项目仅使用 Node.js 内置模块与 Windows PowerShell，没有第三方运行时依赖。
